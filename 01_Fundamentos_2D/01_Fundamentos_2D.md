# Relaciones Geométricas y Cotas Inteligentes 📐

## 🎯 Objetivo

Aprender a definir completamente un croquis 2D aplicando restricciones geométricas antes de colocar cotas numéricas.

## 📌 Conceptos Clave

- **Estado de Croquis:**
  - 🔵 **Azul (Insuficientemente definido):** Faltan cotas o relaciones.
  - ⬛ **Negro (Completamente definido):** Posición y tamaño fijados con respecto al origen.
  - 🔴 **Rojo (Sobredefinido):** Conflictos entre cotas o restricciones contradictorias.

## 🛠️ Ejercicio Práctico

1. Crear una plantilla de placa base partiendo del origen.
2. Aplicar relación de **Igualdad** en los 4 barrenos de fijación.
3. Acotar el diámetro de uno solo para parametrizar el resto.
